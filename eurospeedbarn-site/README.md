# Eurospeedbarn website

Plain HTML/CSS/JS. Open this folder in Phoenix Code and use Live Preview on `index.html`.

- `index.html` – all page content (services, platforms, booking, about, hours)
- `css/styles.css` – colours and fonts are tokens at the top of the file
- `js/main.js` – placeholder booking form (builds a text message to 604-786-2864)
- `images/` – logo and hero photo (cropped from Instagram screenshots; swap in full-res originals)

To add real online booking later, replace the form inside `<section id="book">` with the Square Appointments or Cal.com embed code.
